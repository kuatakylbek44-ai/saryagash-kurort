# Saryagash Kurort

Сарыағаш санаторийлерін салыстыру және брондау сайтының интерактивті алғашқы нұсқасы.

## Жергілікті іске қосу

Осы каталогта:

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Браузерде `http://127.0.0.1:4173` ашыңыз. Құрастыру қадамы мен npm тәуелділіктері қажет емес.

## Құрамы

- Қазақша басты бет, 10 үлгі санаторий, сүзгілер мен сұрыптау.
- Әр санаторийдің жеке беті, бөлмелер, қызметтер, үлгі күнтізбе және байланыс.
- Үш санаторийге дейін салыстыру; бірдей күндер мен адам саны бойынша есеп.
- Браузерде сақталатын таңдаулылар және салыстыру тізімі.
- Менеджер арқылы және онлайн төлеммен брондаудың демо сценарийлері.
- Сая көмекші: жергілікті үлгі деректерге негізделген ереже бойынша жауаптар.
- Жергілікті фото мен Manrope қаріптері; бейімделген CSS және reduced-motion қолдауы.

## Әзірге қосылмаған

Нақты брондау, төлем провайдері, AI/LLM API, менеджерлер/сайт иелерінің қауіпсіз аккаунттары, дерекқор және хабарламалар. Жеке деректер серверге жіберілмейді. Пікірлер ойдан толтырылмаған. Бағалар, рейтингтер, бос орындар мен байланыс деректері — үлгі.

Демо бетте `noindex` бар; нақты санаторий деректері мен жария домен дайын болғанда толық SEO, жеке серверлік URL, sitemap және Search Console қажет.

## Дереккөздер

Фото — Rosemary Media / Unsplash; `asset-source.json`. Қаріптер — Google Fonts; `font-source.json`, лицензия `dist/assets/fonts/OFL.txt`.

## Тексеру

JavaScript синтаксисі, модуль байланыстары, 10 санаторий дерегі және беттердің генерациясы Node арқылы тексерілді. Браузерлік визуалды тексеру құрал рұқсаты болмағандықтан орындалмады.
